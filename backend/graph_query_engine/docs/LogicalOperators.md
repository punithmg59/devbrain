# Logical Operators Specification

## Overview
Logical operators represent intermediate logical query operations.

---

## Supported Operators

1. **`LogicalLookupOperator`**: Logical entity or symbol lookup.
2. **`LogicalExpandOperator`**: Logical graph relationship expansion.
3. **`LogicalFilterOperator`**: Logical predicate filtering.
4. **`LogicalProjectionOperator`**: Logical attribute projection.
5. **`LogicalAggregateOperator`**: Logical aggregation (COUNT, SUM, AVG, MIN, MAX).
6. **`LogicalGroupingOperator`**: Logical group-by keys specification.
7. **`LogicalSortingOperator`**: Logical ordering specification.
8. **`LogicalDeduplicationOperator`**: Logical distinct deduplication.
9. **`LogicalJoinOperator`**: Logical binary join operator.
10. **`LogicalLimitOperator`**: Logical pagination offset/limit.
